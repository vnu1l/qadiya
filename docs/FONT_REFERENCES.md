# QADIYA — FONT REFERENCES

> مرجع محفوظ لاختيارات الخطوط التي طلب مالك المشروع الاحتفاظ بها للاستخدام لاحقًا. هذه **Shortlist** وليست قرارًا نهائيًا للخطوط؛ لا تستبدل الخط الحالي تلقائيًا قبل مرحلة Typography/Design System أو طلب صريح.

## الخطوط المحفوظة

1. **Rubik**
   - Google Fonts: https://fonts.google.com/specimen/Rubik?lang=ar_Arab&preview.lang=ar_Arab
   - مرشح قوي للنصوص العامة، الواجهات، الأزرار، القوائم، والأرقام بسبب وضوحه وطابعه الحديث.

2. **Aref Ruqaa Ink**
   - Google Fonts: https://fonts.google.com/specimen/Aref+Ruqaa+Ink?lang=ar_Arab&preview.lang=ar_Arab
   - مرشح للعناوين المحكمة/الوثائق/الأختام أو اللمسات العربية الرسمية والزخرفية، وليس بالضرورة للنصوص الصغيرة الكثيفة.

3. **Playpen Sans Arabic**
   - Google Fonts: https://fonts.google.com/specimen/Playpen+Sans+Arabic?lang=ar_Arab&preview.lang=ar_Arab
   - مرشح للأسلوب الشخصي أو الملاحظات اليدوية أو عناصر جانبية مرحة/إنسانية عندما يناسب المشهد.

## قاعدة الاستخدام لاحقًا

- راجع الخطوط الثلاثة معًا عند بناء Typography System النهائي.
- اختبر العربية والإنجليزية والأرقام والأوزان وحالات UI الصغيرة قبل اعتماد أي خط.
- يمكن استخدام أكثر من خط بوظائف مختلفة إذا بقي النظام متماسكًا وخفيفًا.
- لا تحمل ملفات خطوط عشوائية داخل المشروع قبل مراجعة الترخيص والأوزان المطلوبة والأداء.
