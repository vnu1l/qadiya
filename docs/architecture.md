# QADIYA Architecture v0.1

## الهدف

بناء لعبة محكمة عربية تعمل بملء الشاشة داخل المتصفح، تشعر كتطبيق لعبة حقيقي لا كموقع صفحات، وتدعم جلسات طويلة مع إعادة اتصال وحالة قضائية authoritative على الخادم.

## الطبقات

- `apps/web`: واجهة Svelte 5، المشاهد، الكاميرا 2.5D، القوائم، ملفات القضية.
- `apps/server`: خادم Colyseus اللحظي، اللوبيات، الصلاحيات، حالة المحكمة.
- `packages/case-engine`: منطق بناء القضايا والتحقق من الاتساق والتوازن.
- `packages/shared`: العقود والأنواع المشتركة بين العميل والخادم.

## قواعد معمارية ثابتة

1. الحقيقة الكاملة للقضية لا تُرسل إلى المتصفح.
2. السيرفر هو المصدر النهائي للحالة القضائية.
3. واجهة اللعبة تبقى داخل Game Shell واحد بدون إعادة تحميل بين المشاهد.
4. الحركة تعتمد أساسًا على `transform` و`opacity` مع طبقات 2.5D بدل 3D ثقيل.
5. الصوت سيكون مسارًا منفصلًا عن حالة اللعبة اللحظية (LiveKit/WebRTC في مرحلة لاحقة).
6. Case Engine مبني على بيانات منظمة؛ الذكاء الاصطناعي لا يكون شرطًا لتقدم الجلسة.
7. لا توجد حالة لعب بلا Recovery Route.
8. المراحل تنظّم المحكمة ولا تقفلها كسلسلة خطوات جامدة.

## Camera Director

المشهد القضائي يُبنى من طبقات خلفية/وسطى/أمامية، ويملك Presets مثل:

- Wide court
- Judge focus
- Witness focus
- Defense table
- Prosecution table
- Defendant focus

الانتقال بينها يتم بدون تبديل صفحة أو إعادة بناء المشهد.
